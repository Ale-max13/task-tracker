# Мини-трекер задач

Простой и аккуратный трекер задач на день, который работает прямо в браузере, без установки и без сервера.

## Возможности

- **Добавление задач.** По кнопке «Добавить» или клавише Enter; пустую задачу добавить нельзя.
- **Отметка выполнения.** Чекбокс слева от задачи, выполненная задача зачёркивается. Отметить можно и щелчком по тексту.
- **Редактирование.** Кнопка ✏️ превращает текст в поле ввода: Enter или щелчок вне поля сохраняет, Esc отменяет.
- **Удаление с подтверждением.** Кнопка 🗑️ спрашивает «Удалить задачу «…»?» с текстом задачи.
- **Сохранение в localStorage.** Задачи и отметки остаются после обновления страницы и перезапуска браузера.
- **Темы оформления.** Светлая, тёмная и системная (по настройке операционной системы); выбор запоминается.
- **Сегодняшняя дата** над карточкой, например «Среда, 25 ноября 2026».
- **Прогресс дня.** Полоска «1 из 3 · 33%»; когда всё выполнено, появляется плашка «🎉 Выполнено!».
- **Пустое состояние.** Когда задач нет, показывается иллюстрация и подсказка «Добавь первую и начни свой день!».
- **Адаптация под iPhone.** Кнопки ✏️ и 🗑️ хорошо видны на сенсорных экранах, область нажатия не меньше 44×44 px, страница не увеличивается при вводе текста.

## Технологии

- HTML
- CSS (CSS-переменные для тем, медиазапросы для телефонов)
- JavaScript без библиотек и фреймворков

Сборка и установка зависимостей не нужны. Единственный внешний ресурс — шрифт заголовка Pacifico из Google Fonts.

## Как запустить

1. Скачайте или склонируйте репозиторий.
2. Откройте файл `index.html` в браузере.

Онлайн-версия (GitHub Pages): https://ale-max13.github.io/task-tracker/

## Структура проекта

```
index.html   — разметка страницы
style.css    — оформление и цвета светлой и тёмной темы
script.js    — задачи: добавление, отметка, редактирование, удаление, сохранение, прогресс
theme.js     — переключатель тем
date.js      — сегодняшняя дата
```

## Ручное тестирование

- Проверено в Chrome (Windows 11)
- Проверено в эмуляторе iPhone (Chrome DevTools, режим устройства)
- Проверено на iPhone в Safari: светлая и тёмная тема, добавление, редактирование, удаление с подтверждением, прогресс 100%
- Страница не увеличивается при вводе текста в поле
- Кнопки ✏️ и 🗑️ удобно нажимать пальцем
