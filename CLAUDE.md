# Мини-трекер задач

## О проекте

Простой трекер задач в браузере. Только чистые **HTML, CSS и JavaScript**:
без библиотек, фреймворков, сборщиков и npm-пакетов. Проект открывается
двойным щелчком по `index.html`, сервер не нужен.

## Версия 1 (MVP): что должно работать

1. **Добавить задачу.** Пользователь вводит текст в поле и нажимает кнопку
   «Добавить» (или Enter). Пустую задачу добавить нельзя.
2. **Отметить задачу выполненной.** У каждой задачи слева есть чекбокс.
   Поставили галочку — текст задачи зачёркивается. Сняли галочку —
   зачёркивание пропадает. Щелчок по тексту задачи тоже ставит и снимает
   галочку: чекбокс и текст лежат внутри одного `<label>`.
3. **Удалить задачу.** Справа у каждой задачи есть кнопка со значком 🗑️
   и всплывающей подсказкой «Удалить задачу» (атрибуты `title` и
   `aria-label`). По нажатию браузер спрашивает «Удалить задачу «текст
   задачи»?» стандартным окном (`confirm`). «ОК» удаляет задачу, «Отмена»
   оставляет её. Кнопка лежит вне `<label>`, чтобы щелчок по ней не ставил
   галочку.
4. **Сохранение задач.** Список хранится в `localStorage` браузера под
   ключом `tasks` (для каждой задачи — текст и отметка выполнения).
   Список сохраняется после добавления, отметки и удаления, а при открытии
   страницы загружается. Если `localStorage` недоступен или данные
   испорчены, страница продолжает работать с пустым списком.
5. **Прогресс.** Между заголовком и полем ввода — строка «Прогресс … 1 из 3 · 33%»
   и полоска, заполненная на процент выполненных задач (процент округляется
   до целого, `Math.round`). Когда задач нет, прогресс спрятан. Когда
   выполнены все задачи, полоска становится градиентной, а под списком
   появляется плашка «🎉 Выполнено!». Пересчитывает всё функция
   `updateProgress()` в `script.js`: она вызывается после добавления,
   отметки, снятия отметки, удаления и после загрузки страницы.

Пока **не делаем**: редактирование, фильтры, даты, категории.
Это темы для следующих версий.
Не добавляй ничего сверх MVP без моей просьбы.

## Структура файлов

```
task-tracker/
├── index.html   — разметка страницы
├── style.css    — внешний вид и цвета обеих тем (см. «Оформление» и «Темы»)
├── theme.js     — переключатель тем (подключён в <head>)
├── script.js    — логика задач (добавление, отметка, удаление, сохранение, прогресс)
└── date.js      — сегодняшняя дата над карточкой
```

## Оформление

Ниже описана светлая тема. Тёмная — в разделе «Темы».

- Фон страницы — мягкий градиент: лавандовый → розовый → кремовый.
- Над карточкой по центру — сегодняшняя дата, например «Среда, 25 ноября 2026»
  (`<p id="today-date">`). Берётся с часов компьютера при открытии страницы
  (`date.js`, `toLocaleDateString('ru-RU')`), день недели с большой буквы.
  Год дописывается отдельно через `getFullYear()`, без «г.» в конце.
  Обычный шрифт, 15px, цвет `#4b5563`.
- Всё содержимое лежит в карточке `<main class="card">`: белая
  полупрозрачная, по центру, ширина до 420px, скруглённые углы, лёгкая тень.
- Заголовок «Мои задачи» — шрифт Pacifico из Google Fonts (подключён
  в `<head>` в `index.html`), цвет тёмный, почти чёрный (`#1f2937`).
  Остальной текст — системный шрифт
  (`"Segoe UI", Roboto, Arial, sans-serif`).
- Поле ввода и кнопка «Добавить» стоят в одной строке (`<div class="add-row">`),
  крупные, со скруглёнными углами. Кнопка светло-лавандовая с тёмным текстом.
- У списка задач нет точек-маркеров и отступа слева, задачи стоят ровно
  под полем ввода. Чекбокс с текстом слева, значок 🗑️ прижат вправо.
- Чекбоксы задач нарисованы через CSS: стандартный вид выключен
  (`appearance: none`), но это по-прежнему настоящий `<input type="checkbox">`.
  Неотмеченный — белый квадратик 16×16 с лавандовой рамкой (`#a5b4fc`).
  Отмеченный — сиреневый фон и рамка (`#818cf8`) с белой галочкой (SVG).
- У кнопки удаления нет рамки и фона, виден только значок 🗑️. Он бледный
  (`opacity: 0.35`), при наведении становится ярким; курсор — «рука».
  На телефонах значок всегда хорошо виден (`opacity: 0.7`): правило
  `@media (hover: none), (max-width: 600px)` — нет мышки ИЛИ экран
  не шире 600px. В том же правиле область нажатия кнопки — не меньше
  44×44px (`min-width`/`min-height`), сам значок прежнего размера.
- Поле ввода — 16px (`font: inherit` от страницы), чтобы Safari на iPhone
  не увеличивал страницу при нажатии. Не делай шрифт поля меньше 16px.
- **Пустое состояние** (`<div class="empty-state">` сразу после
  `<ul id="task-list">`): когда задач нет, под полем ввода по центру
  показываются картинка 72px и два текста.
  - Картинка — SVG прямо в `index.html`: планшет с градиентом корпуса
    `#c4b5fd` → `#8b5cf6`, серый металлический зажим, белый лист с тремя
    строками-чекбоксами (два пустых с рамкой `#a5b4fc`, третий отмечен
    `#818cf8` с белой галочкой), лёгкая тень; справа наискосок жёлтый
    карандаш с розовым ластиком; вокруг искорки-плюсики и точки розового
    и лавандового цвета. Цвета картинки одинаковые в обеих темах.
  - «Задач пока нет» — 14px, жирный.
  - «Добавь первую и начни свой день!» — 12px, цвет `#6b7280`.
  - Показ и скрытие делает только CSS, без JavaScript:
    `#task-list:empty + .empty-state { display: block; }`.
    Поэтому между `<ul id="task-list">` и `</ul>` в HTML не должно быть
    пробелов и переносов строк, иначе `:empty` не сработает.
- **Прогресс** (`<div id="progress">` между заголовком и полем ввода):
  - строка: слева «Прогресс», справа «1 из 3 · 33%» — 12px, цвет `#6b7280`;
  - полоска высотой 7px, полностью скруглённая: фон `#ede9fe`,
    заполнение `#818cf8`, ширина плавно меняется (`transition`);
  - на 100% заполнение — градиент `#818cf8` → `#f472b6` (класс `is-complete`);
  - прячется атрибутом `hidden`, когда задач нет. Элементам с `hidden`
    не задавай `display` в CSS — иначе они не спрячутся.
- **Плашка «🎉 Выполнено!»** (`<p id="done-badge">` под списком и пустым
  состоянием): видна только на 100%. По центру, текст 16px жирный, эмодзи
  20px (в отдельном `<span class="done-emoji">`), отступы 10px сверху/снизу
  и 22px по бокам, полностью скруглённые края. Фон — градиент слева направо
  `#e0e7ff` → `#fbcfe8`, текст `#1e1b4b`.

## Темы

**Переключатель.** Слева вверху страницы, три кнопки в одной «таблетке»:
«☀️ Светлая», «🌙 Тёмная», «💻 Системная». Выбранная кнопка подсвечена
(у неё `aria-pressed="true"`).

**Поведение (`theme.js`):**
- При первом открытии тема светлая.
- Выбор (`light`, `dark` или `system`) хранится в `localStorage` под ключом
  `theme` и сохраняется после обновления.
- «Системная» берёт светлую или тёмную тему по настройке Windows
  (`prefers-color-scheme`) и переключается сама, если настройку поменять.
- Тема включается меткой на теге `<html>`: `data-theme="light"` или
  `data-theme="dark"`. `theme.js` подключён в `<head>`, чтобы не было
  «вспышки» светлой темы при обновлении.

**Как устроены цвета (`style.css`):** все цвета — CSS-переменные.
Светлые значения в `:root`, тёмные в `:root[data-theme="dark"]`.
Сами правила для обеих тем одинаковые. Новый цвет добавляй переменной
в оба блока.

**Цвета тёмной темы:**
- Фон страницы: градиент `#1e1b4b` → `#3b1e3f` → `#2a2416`.
- Карточка: тёмная полупрозрачная `rgba(38, 41, 64, 0.95)` — чуть светлее
  фона страницы, с рамкой 1px `rgba(165, 180, 252, 0.25)`. В светлой теме
  рамки нет (`--card-border: none`).
- Заголовок и текст задач: `#e5e7eb`.
- Дата над карточкой: `#cbd5e1`.
- Подсказка «Добавь первую и начни свой день!» в пустом состоянии: `#9ca3af`.
- Прогресс: текст `#9ca3af`, фон полоски `#2e3150`, заполнение то же
  `#818cf8` (и тот же градиент на 100%).
- Плашка «🎉 Выполнено!»: фон — градиент `rgba(129, 140, 248, 0.35)` →
  `rgba(244, 114, 182, 0.35)`, текст `#fce7f3`.
- Поле ввода: фон `#161827`, рамка `#3f4258`.
- Кнопка «Добавить», рамки и отмеченные чекбоксы: `#a5b4fc`;
  текст на кнопке тёмный `#1e1b4b`.
- Пустой чекбокс — фон `#161827`. Галочка в отмеченном чекбоксе тёмная
  (`#1e1b4b`), потому что белая плохо видна на светлом `#a5b4fc`.

## Правила кода

- Комментарии в коде пиши **на русском**, простыми словами: что делает
  этот кусок и зачем.
- Код должен быть простым и понятным новичку. Лучше несколько понятных строк,
  чем одна «хитрая».
- Используй современный JavaScript: `const` и `let` (не `var`),
  `addEventListener` (не `onclick` в HTML).
- Текст задачи вставляй через `textContent`, не через `innerHTML`, чтобы
  введённый текст не мог сломать страницу.
- Понятные имена переменных и функций на английском, например `addTask`,
  `taskList`.
